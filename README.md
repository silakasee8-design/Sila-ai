# SILA AI — deployment and integrations

## Render deployment

1. Create a Render Blueprint from this repository using `render.yaml`.
2. Render creates the web service and PostgreSQL database. If your selected Render plan does not support the database plan in the blueprint, create PostgreSQL manually and connect its internal connection string as `DATABASE_URL`.
3. Add `OPENAI_API_KEY` in the web service environment.
4. `JWT_SECRET` and `INTEGRATION_API_KEY` are generated by the Blueprint. Keep them private.
5. Deploy and check `https://YOUR-SERVICE.onrender.com/api/health`.

The health response should report `aiConfigured: true`, `databaseConfigured: true`, and `integrationApiConfigured: true`.

## Website and mobile API

Call the integration endpoint over HTTPS:

```bash
curl -X POST https://YOUR-SERVICE.onrender.com/api/integrations/chat \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_INTEGRATION_API_KEY" \
  -d '{"message":"Review this business idea","mode":"business"}'
```

Supported modes are `general`, `grammar`, `code`, `business`, and `document`. Never expose the integration key in a public browser bundle or mobile app. For public client apps, use a small server-side proxy or user login instead.

Check available integration modes:

```bash
curl https://YOUR-SERVICE.onrender.com/api/integrations/modes
```

## WhatsApp webhook setup

Set `WHATSAPP_VERIFY_TOKEN` to a private random value. In Meta Developers, configure the callback URL as:

```text
https://YOUR-SERVICE.onrender.com/api/webhooks/whatsapp
```

Use the same verify token in Meta. Subscribe to the WhatsApp `messages` webhook field. The current webhook validates Meta's subscription challenge and processes incoming text into a response payload. Sending the response back through the WhatsApp Cloud API still requires `WHATSAPP_ACCESS_TOKEN` and `WHATSAPP_PHONE_NUMBER_ID`; do not publish either secret.

## Gmail OAuth setup

Create OAuth credentials in Google Cloud, enable the Gmail API, and set the authorized redirect URI to:

```text
https://YOUR-SERVICE.onrender.com/api/integrations/gmail/callback
```

Set `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, and `GOOGLE_REDIRECT_URI` in Render. Gmail integration is not enabled until OAuth routes and token storage are implemented; do not add credentials until that code is deployed.

## Security

Never commit `.env`, API keys, access tokens, OAuth secrets, passwords, or database URLs. Use HTTPS, rotate integration keys, and add rate limiting before distributing the API publicly.
